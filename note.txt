RAG:
RAG helps the LLM retrieve relevant information from a knowledge base before generating an answer.

AI Agent:
An AI Agent can decide what action to take and which tools to use to complete a task.

MCP:
MCP is a standard protocol that allows AI applications to connect with and use external tools and data.

Your project in one line
RAG gives the Agent knowledge, tools give the Agent capabilities, and the Agent decides how to use those capabilities to complete the student's task.

-------------------------------------

Where MCP comes in

After your Agent works properly, then add MCP.

Without MCP:

AI Agent
   ↓
Python Functions

With MCP:

AI Agent
   ↓
MCP
   ↓
Tools
 ┌──────────────┬──────────────┬──────────────┐
 ↓              ↓              ↓              ↓
Resume       Placement      Skill Gap        RAG 
Tool         Tool           Tool             Tool

MCP gives a standard way for the AI application to discover and use tools.
So don't start MCP before your Agent works.
